# Results

## `grouped_cv_deberta/`

This directory contains the ordinary grouped cross-validation reference run.
It separates paired email contexts across folds, but attack categories may
still occur in both training and validation folds. DeBERTa achieved perfect
mean scores in this easier setting.

## `category_disjoint_cv_deberta/`

This directory contains the primary experiment. Every validation fold holds
out three complete attack categories, while preserving paired benign/attack
contexts within the same fold. It includes:

- fold assignments and protocol summaries;
- DeBERTa configuration, fold metrics, out-of-fold predictions, training
  history, and metric summary;
- Linear SVM configuration, fold metrics, out-of-fold predictions, and metric
  summary;
- the direct DeBERTa-versus-SVM comparison table; and
- a fold-2 analysis of the observed DeBERTa over-defense behavior.

The `.pt` model checkpoints are intentionally excluded from version control.
They can be regenerated by running the main notebook.

## `pilot_validation/`

This directory preserves CSV and JSON outputs from the early single-split
DeBERTa validation and held-out test exploration, including sanity-check
outputs. These files document model debugging and threshold selection, but are
not used as the primary conclusion in the Assignment 2 report. The final
reported reality-check result is the category-disjoint cross-validation above.
